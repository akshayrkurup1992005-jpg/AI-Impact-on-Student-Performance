## 🚀 Project Overview

**AI Impact on Student Performance** is a Data Analytics and Visualization project developed using **Microsoft Excel and Microsoft Power BI**.

The project analyzes student academic performance and explores different patterns related to **Artificial Intelligence (AI) usage**.

The complete workflow starts from raw data, followed by data cleaning, validation, Excel analysis, Power BI visualization, dashboard development, and insight generation.

### 🔍 What does this project analyze?

- 👨‍🎓 Student academic performance
- 🤖 AI usage among students
- 👥 AI users vs non-AI users
- 🧰 AI tools used by students
- 🎯 AI usage purposes
- 📚 Attendance percentage
- 🎓 Grade-level performance
- 👥 Gender-wise student distribution
- 🧠 AI dependency
- 📈 Final academic score

---

# 🎯 Project Objectives

The main objectives of this project are:

- Clean and prepare the raw student dataset
- Identify duplicate and blank records
- Check missing values
- Validate categorical data
- Validate numerical data
- Analyze student distribution
- Analyze AI adoption among students
- Compare AI users and non-AI users
- Analyze AI tools and usage purposes
- Compare AI usage with academic performance
- Analyze attendance and final score
- Analyze grade-level performance
- Build an interactive Power BI dashboard
- Provide student-level analysis
- Generate meaningful insights
